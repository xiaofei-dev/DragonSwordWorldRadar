# Archive

This directory contains retired implementations preserved for source history,
comparison, and rollback research. Archived projects are not active build,
package, installation, or deployment targets.

## Contents

| Directory | Status |
|---|---|
| `DragonSwordWorldRadar/` | Frozen external-renderer Radar implementation superseded by `DragonSwordNativeWorldRadarPostRender` |

Do not enable an archived Radar beside the maintained native Radar. Do not
promote archived behavior into an active product without an explicit product
decision and fresh validation.

The former `DragonSwordNativeWorldRadar` and
`DragonSwordWorldRadarObjectState` prototypes are intentionally absent from the
working tree. Their source remains available in Git history rather than as
additional live archive copies.
