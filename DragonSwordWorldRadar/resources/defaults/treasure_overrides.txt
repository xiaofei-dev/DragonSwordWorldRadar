# Treasure Radar override rules
#
# Ignore a treasure by its full save-state ID:
#   ignore 10220122
#
# Ignore a treasure by the short type label shown by the radar:
#   ignore U_10222
#
# A short label can match more than one duplicate data row. In that case,
# every matching row is ignored.
#
# Map one source ID to an authoritative save-state ID:
#   alias 12345 67890
#
# Alias rules currently require full numeric IDs.
