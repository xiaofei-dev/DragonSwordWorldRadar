[size=6][b]Native Map and Radar Enhancer[/b][/size]

Adds Treasure, Boss, Assault, mini-game, and Area Quest markers to the minimap and world map, plus compact-radar Bird Eggs, height guidance, an in-game clock, and localized settings. Rendering stays inside the game; there is no external overlay window.

[quote][b]Before installing[/b]
Close the game. Use the Installer if you already have Mods or are unsure about UE4SS. Do not mix UE4SS packages or use the older Treasure Radar Overlay. Native Radar can be used alongside [url=https://www.nexusmods.com/dragonswordawakening/mods/251]DragonSword Auto Pickup[/url].[/quote]

[size=4][b]Features[/b][/size]

[list]
[*]Separate RADAR and MAP category switches.
[*]Configurable Settings, Enable, and Disable keys, with key selection in Setup during Install, Update, or Repair.
[*]Treasure completion filtering and AVAILABLE / ALL display modes for Area Quests and Assaults.
[*]Compact height guidance for Treasure, Area Quests, and supported Fly / Mole / Wave mini-games. Height switches do not hide the underlying markers.
[*]11 interface languages: English, Japanese, Korean, Simplified Chinese, Traditional Chinese, French, German, Spanish, Russian, Thai, and Portuguese (Brazil), plus AUTO.
[*]Settings remain available while Radar is Off, On, or Faulted.
[/list]

Bird Eggs and height guidance are compact-radar only. Markers do not bypass treasure-map, puzzle, quest, activity, time, or cooldown requirements. Treasure colors: white for regular treasure, green for activity/task rewards, orange for treasure-map or legendary treasure, and blue for puzzles.

[size=4][b]Install and start[/b][/size]

[list=1]
[*]Download and extract [b]Installer (Recommended)[/b] from the [url=https://www.nexusmods.com/dragonswordawakening/mods/254?tab=files]Files section[/url].
[*]Close the game and run Setup. Select [code]DS\Binaries\Win64\DSClient-Win64-Shipping.exe[/code].
[*]Review the detected Install / Update / Repair action and key choices, then confirm. Setup handles the tested UE4SS runtime when needed; conversion requires a verified backup.
[*]Load your save into an open-world area, wait until you can control your character, and press the Enable key.
[/list]

Defaults are [b]F6: Settings[/b], [b]F7: Enable / Resynchronize[/b], and [b]F8: Disable[/b]. Radar starts Off and must be enabled again after returning to the main menu or loading another save/world. Dungeons and instanced activities are outside the supported map scope.

[size=4][b]Custom keys and language[/b][/size]

Use Setup Update / Repair, or close the game and edit:
[code]DS\Binaries\Win64\ue4ss\Mods\DragonSwordNativeWorldRadarPostRender\config\hotkeys.ini[/code]
[code][hotkeys]
settings_hotkey=INSERT
enable_hotkey=HOME
disable_hotkey=PAGEUP[/code]

Restart to apply. Use three different keys: F1-F24, A-Z, 0-9, NUM0-NUM9, HOME, END, PAGEUP, PAGEDOWN, INSERT, DELETE, or SPACE. Modifier combinations are unsupported. Avoid game and other Mod bindings. Invalid runtime key settings fall back to F6/F7/F8.

Choose AUTO, the first language option, to follow the game language. AUTO stays selected and refreshes when Settings opens or Radar is enabled. A manual language choice stays fixed until you select AUTO again. Changing categories or language does not overwrite hotkeys.

[size=4][b]Other download options[/b][/size]

[list]
[*][b]Manual - No UE4SS[/b]: Mod-only files for an existing compatible ExperimentalNested installation.
[*][b]Manual - With UE4SS[/b]: Mod and tested UE4SS v3.0.1-Beta0-g1c1a1497, for a clean installation without existing UE4SS.

Manual packages do not perform backup, update, configuration merging, or rollback. Read the included README. Back up existing settings before copying an update; Setup is recommended. Never overwrite another Mod's [code]ue4ss\Mods\mods.txt[/code]; keep its entries and merge only:
[code]DragonSwordNativeWorldRadarPostRender : 1[/code]

A compatible-looking version number alone does not prove runtime compatibility. Setup checks the game image and nested UE4SS structure; feature checks still fail safely if incompatible.

[size=4][b]Uninstall and support[/b][/size]

Close the game and use Setup [b]Uninstall[/b]. Keep UE4SS if other Mods use it.

If markers, menus, or text behave incorrectly, report the steps, input device, resolution/display mode, other Mods, and a screenshot in the [url=https://www.nexusmods.com/dragonswordawakening/mods/254?tab=posts]Posts section[/url]. Include the exact menu sequence for controller-related issues. For missing text, test without font-replacement PAKs.

Debug logging is Off by default. Set [code]debug_logging=true[/code] in the Mod's [code]config\diagnostics.ini[/code] before starting the game, reproduce once, and attach:
[code]DS\Binaries\Win64\ue4ss\Mods\DragonSwordNativeWorldRadarPostRender\runtime\logs\DragonSwordNativeWorldRadarPostRender.Native.log[/code]
Turn debugging off afterward. For startup crashes, also include UE4SS.log and INSTALL-RECORD.txt if available. Use a direct text attachment or a trusted host without download wrappers.
