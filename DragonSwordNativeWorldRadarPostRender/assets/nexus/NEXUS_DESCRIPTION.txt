[size=6][b]DragonSword Native Map and Radar Enhancer v2.2.1[/b][/size]

Adds configurable Treasure, Boss, Assault, mini-game, and Area Quest markers to the minimap and expanded world map, plus Bird Egg markers, an in-game clock, compact-radar height guidance, localization, and a responsive in-game settings panel. It uses native in-game rendering and is compatible with [url=https://www.nexusmods.com/dragonswordawakening/mods/251]DragonSword Auto Pickup[/url].

[quote][b]WARNING - INCOMPATIBLE MOD[/b]
Do not use Native Map and Radar Enhancer with the older [b]Treasure Radar Overlay[/b]. Disable or remove Treasure Radar Overlay before installing this Mod.
Do not delete UE4SS if it is required by Auto Pickup or other Mods.[/quote]

[size=4][b]Height indicators[/b][/size]

[list]
[*][b]Treasure[/b] - Shows the existing category-colored arrow for the nearest eligible Treasure.
[*][b]Area Quest[/b] - Applies to every visible Area Quest. The normal black frame displays three white dots within the selected height band. Outside the band, the frame becomes an upward or downward black triangle.
[*][b]Mini-game[/b] - Shows a small solid up/down triangle directly below the nearest visible Fly, Mole, or Wave marker. Its color follows the mini-game type.
[/list]

Area Quest and mini-game guidance use a calibrated player-height comparison with an inclusive +/-500 neutral range. All height indicators are compact-radar only. Turning an indicator off does not hide its marker. Missing or ambiguous height data hides only the guidance shape and never hides the underlying marker.

[size=4][b]Treasure marker colors and requirements[/b][/size]

[list]
[*][b]White - Regular Treasure[/b] - Standard Treasure that can normally be collected when reached.
[*][b]Green - Mini-game or Task Reward[/b] - Complete the associated activity when required. Only some Mole chests are linked to a specific Mole task; not every Mole chest has a task requirement.
[*][b]Orange - Treasure Map or Legendary Treasure[/b] - Open the corresponding Treasure Map before attempting to collect it.
[*][b]Blue - Puzzle Treasure[/b] - Complete the related puzzle or interaction before collecting it.
[/list]

The Mod displays locations and availability information only. It does not bypass Treasure Map, task, puzzle, cooldown, time, or activity requirements.

[size=4][b]Controls and startup[/b][/size]

[list]
[*][b]F6[/b] - Opens Radar Settings while Radar is Off, On, or Faulted.
[*][b]F7[/b] - Activates or resynchronizes Radar after a fully loaded open-world area is ready.
[*][b]F8[/b] - Disables Radar.
[/list]

Radar starts disabled whenever the game launches. Load a fully loaded open-world area and press F7 to activate it. Dungeons and other instanced activities are not supported. Returning to the main menu or loading another save or World disables Radar; press F7 again after loading finishes.

The F6 status section shows the current state and provides Enable, Disable, or Retry without closing the page. Bug Report opens this Mod's Nexus Posts page.

[size=4][b]Languages[/b][/size]

F6 offers 11 explicit language choices: English, Japanese, Korean, Simplified Chinese, Traditional Chinese, French, German, Spanish (Spain), Russian, Thai, and Portuguese (Brazil).

On the first F6 opening or F7 activation after upgrading, a legacy automatic preference is resolved from the current game language and saved as the matching explicit language. If the game language cannot be detected, English is used. You can select another language directly in F6 at any time.

[size=4][b]UE4SS requirement[/b][/size]

Native Map and Radar Enhancer requires a current compatible UE4SS runtime from August 2026 or later. The tested release runtime is UE4SS v3.0.1-Beta0-g1c1a1497.

The One Click Installer and Manual - Includes UE4SS package handle UE4SS automatically. Do not manually mix files from different UE4SS packages.

[size=4][b]Manual installation[/b][/size]

Copy the Radar Mod folder into:
[code]Win64\ue4ss\Mods[/code]

Do not overwrite an existing:
[code]Win64\ue4ss\Mods\mods.txt[/code]

Keep all entries for other Mods and add or replace only:
[code]DragonSwordNativeWorldRadarPostRender : 1[/code]

Use Manual - Includes UE4SS only for a clean installation. Use the One Click Installer if the existing setup is uncertain.

[size=4][b]Settings[/b][/size]

Each supported category has an independent RADAR option, and supported expanded-world-map categories also have a MAP option. Bird Eggs are compact-radar only and do not have a MAP option.

Treasure, Area Quest, and mini-game height guidance have independent switches. These switches affect height guidance only, not marker visibility.

[b]AREA QUEST MODE[/b]
[list]
[*][b]AVAILABLE[/b] - Shows unfinished Area Quests whose normal prerequisites are currently satisfied.
[*][b]ALL[/b] - Shows applicable unfinished catalog entries while continuing to exclude confirmed completed entries.
[/list]

[b]ASSAULT MODE[/b]
[list]
[*][b]AVAILABLE[/b] - Uses the normal Assault availability, time, state, and cooldown rules.
[*][b]ALL[/b] - Displays all 40 catalog locations, including currently unavailable Assaults. This is display-only and does not make them playable.
[/list]

Settings are saved automatically.

[size=4][b]Uninstall[/b][/size]

Recommended method: close the game, run the latest installer, and choose Uninstall.

For manual removal, delete:
[code]Win64\ue4ss\Mods\DragonSwordNativeWorldRadarPostRender[/code]

Then remove only the DragonSwordNativeWorldRadarPostRender line from:
[code]Win64\ue4ss\Mods\mods.txt[/code]

Keep UE4SS, unrelated Mods, game saves, and every other mods.txt entry.
