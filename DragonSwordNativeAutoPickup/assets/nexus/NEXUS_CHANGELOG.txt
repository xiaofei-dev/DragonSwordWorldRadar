1.3.1
Fixed Setup Update and Repair ignoring newly selected toggle and interaction fallback keys.
Added editable key selectors and an explicit confirmation for Install, Update, and Repair.
Preserved other settings, unchanged key formatting, and unrelated Mods when changing keys.
Kept uncommitted key choices after cancellation or failure and restored previous files on a failed installation.
Fixed a startup timing issue where Auto Pickup could remain disabled if the game's interactable default object was not ready yet.
Added a fail-closed startup retry every 250ms for up to 30 seconds.
Full compatibility and selector checks still run before F9, scanning, or pickup becomes available.
Kept the native pickup selector and input route; the installer refresh does not change native gameplay behavior.
Kept full 15x and 20x range for gather and interactable-animal targets.
Capped short-lived item drops at the stable 10x range inside the 15x and 20x PAKs to reduce stuck prompt lists while moving quickly.
Reused the exact 1.3.0 3x, 5x, and 10x PAK files.
Added strict PAK checks for 69 targets, 138 entries, zero treasure targets, and byte-identical 10x drop entries in the 15x and 20x variants.
Updated the installer and all packages to 1.3.1 with safe owned 1.3.0 upgrade support.

1.3.0

Fixed sustained pickup stalls and repeated interaction attempts.
Added a single global pending action to prevent overlapping pickup inputs.
Added dispatch-aware pickup recovery.
Added one retry after 200ms when no interaction dispatch is detected.
Added a temporary 1500ms backoff for the exact unresponsive target.
Other available targets can continue while one target is cooling down.
Replaced activation-long target quarantine with automatic recovery.
Changed F9 handling to require a real physical press and release.
Fixed keyboard repeat unexpectedly toggling Auto Pickup again.
Replaced the fixed selector address with automatic runtime selector resolution.
Added two independent selector checks that must resolve the same address.
Removed the game EXE hash as an activation or address-selection requirement.
Game hashes are now diagnostic only.
Improved compatible game-update address relocation support.
Incompatible or ambiguous game updates now keep Auto Pickup safely disabled.
Reduced active scanning and post-pickup scanning from 33ms to 25ms.
Kept the 33ms idle scanning interval.
Improved World, save, Pawn, controller, mount, and interaction-context recovery.
Added STARTING, ENABLED, DISABLED, and NOT READY status notifications.
Added a translucent top-center status card with automatic fade-out.
Fixed debug_logging changing pickup behavior.
Detailed diagnostic logging remains disabled by default.
Expanded every range PAK to 50 gather or animal assets and 19 monster-drop assets.
Added ordinary meat, aged meat, and other reviewed F-pickable monster drops to every range PAK.
Treasure chests and Treasure-type assets remain excluded.
Moved all range scaling into the PAK to prevent accidental double scaling.
Added safer installer Repair and Upgrade ownership records.
Supported range PAKs can now be replaced or removed by exact product filename.
Historical PAK hashes are no longer required for replacement or removal.
Upgrades preserve config.ini and unrelated Mods.
Published Installer, Manual No UE4SS, Manual With UE4SS, and Standalone Range PAK packages.
